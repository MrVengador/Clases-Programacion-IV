## 🎮 Descripción del Proyecto

El repositorio contiene la estructura completa del proyecto de Unreal Engine 5. A lo largo de la asignatura, el proyecto irá evolucionando progresivamente incorporando:

* **Mecánicas del Jugador:** Controles con Enhanced Input System, movimiento 3D, salto, interacción y mecánicas avanzadas.
* **Sistemas de Juego:** Instanciación dinámica, proyectiles, detección y gestión de daño mediante Blueprint Interfaces.
* **Inteligencia Artificial (IA):** Controladores de enemigos, NavMesh, rutinas de patrullaje y percepción.
* **Interfaz de Usuario (HUD / UI):** Barras de estado, menús de pausa, temporizadores e interacción con UMG.
* **Integración y Pulido:** Iluminación, efectos visuales (VFX) y flujo completo de juego hasta el empaquetado ejecutable (`.exe`).
